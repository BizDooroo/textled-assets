# textled-assets

Optional resource packs for the 빛말 (Bitmal) LED sign app by BizDooroo. The app downloads them only when a user asks,
through jsDelivr at a pinned tag (`https://cdn.jsdelivr.net/gh/BizDooroo/textled-assets@<tag>/packs/<id>/<file>`); see `BUNDLES.md`.
Each bundle lives on its own orphan branch and is published as an immutable tag; `main` holds only this README,
the license of our own content, the bundle list, and the look-submission form.
